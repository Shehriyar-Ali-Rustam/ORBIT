# Meeting Notes

Team meeting records, decisions, and retrospectives.

## Naming convention

Use `YYYY-MM-DD-topic.md` format so files sort chronologically:

```
meetings/
├── 2026-05-14-weekly-standup.md
├── 2026-05-16-launch-retro.md
├── 2026-05-20-strategy-review.md
└── decisions/
    └── 2026-05-15-clerk-production-migration.md
```

## Suggested contents

- Weekly / monthly standup notes
- Strategy sessions
- Post-mortems and retrospectives
- Decision log (key architectural, product, and business decisions with rationale)
- 1-on-1 notes (kept private to relevant people)

## Template

Copy this format for new notes:

```markdown
# [Topic] — YYYY-MM-DD

**Attendees:** ...
**Duration:** ...

## Agenda
- ...

## Decisions
- ...

## Action items
- [ ] Owner: task by date
```
