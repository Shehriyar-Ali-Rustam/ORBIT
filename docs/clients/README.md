# Client Documents

Per-client folders with proposals, contracts, and correspondence.

## Structure

Create a subfolder per client, using kebab-case:

```
clients/
├── acme-corp/
│   ├── proposal-2026-05.pdf
│   ├── signed-contract.pdf
│   ├── invoices/
│   └── meeting-notes.md
├── xyz-startup/
│   └── ...
```

## Suggested per-client contents

- Signed proposals
- Contracts and SOWs
- Invoices (PDF)
- Project brief and requirements
- Meeting notes
- Post-project retrospectives
- Testimonials and review permissions

**Careful:** Never commit signed contracts to a public repo. This repo is private but consider whether cloud storage with client access is a better fit for signed originals.
